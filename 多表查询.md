多表查询

查询员工及其所属部门：

```
select * from employees as e inner join departments as d on e.department_id = d.department_id;
```

查询所有员工及其所属部门，包括没有部门的员工：

```
 select * from employees as e left join departments as d on e.department_id = d.department_id;
```

查询所有部门及其员工

```
 select * from departments as d left join employees as e on d.department_id=e.department_id;
```

自连接查询领导

```
SELECT e.employee_name AS 员工, e.job AS 职位,m.employee_name AS 直属领导
FROM employees AS e
LEFT JOIN employees AS m
    ON e.manager_id = m.employee_id;
```



查询所有员工的姓名、职位和部门名称。

```
select employee_name, job, department_name from employees  inner join departments on employees.department_id = departments.department_id;
```

查询技术部的所有员工。

```
select * from departments inner join employees on departments.department_id = employees.department_id 
where departments.department_name='技术部';
```

```
select * from employees e inner join departments d on e.department_id=d.department_id where department_name='技术部'; 
```

查询工资大于 12000 元员工的姓名、工资和部门。

 ```
 select * from departments inner join employees on departments.department_id = employees.department_id where salary > 12000;
 select employee_name, salary, department_name from departments as d inner join employees as e on d.department_id=e.department_id where salary > 12000;
 ```

查询所有部门及其员工，包括没有员工的部门。

```
SELECT d.department_name, e.employee_name FROM departments AS d LEFT JOIN employees AS e  ON d.department_id = e.department_id;
select * from departments as d left join employees as e on d.department_id=e.department_id;
```

查询所有员工及其部门，包括没有部门的员工。

```
select * from employees as e left join departments as d on e.department_id=d.department_id;
```

查询每名员工及其直属领导。

```
select * from employees as e1 inner join employees as e2 on e1.manager_id=e2.employee_id;
```

查询没有直属领导的员工。

```
select * from employees where manager_id is null;
```

查询部门位于北京的所有员工。

```
select * from employees as e inner join departments as d on e.department_id=d.department_id where location='北京';
```

查询员工姓名、部门名称和部门所在地。

```
select employee_name,department_name, location from employees as e inner join departments as d on e.department_id=d.department_id;
```

查询所有项目及其负责部门。

```
select * from projects as p inner join departments as d where p.department_id=d.department_id;
```
